# 9. Architecture Amendment Request (template)

Filed in docs/architecture/amendments/ as AMR-NNN.md. Nothing is built against an amendment until Sam accepts it and the Architecture & Boundary document is revised.

```text
AMR-NNN
Slice:            <n>
Decision(s):      <D#, Section #>
Collision:        <one paragraph — what the implementation cannot do without violating it>
Options:          <a> honour as written at cost X  <b> amend to Y  <c> defer capability>
Recommendation:   <one of a/b/c>
Status:           OPEN | ACCEPTED | REJECTED
```
